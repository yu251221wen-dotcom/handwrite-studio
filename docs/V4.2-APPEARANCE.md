# V4.2 排版与手写外观架构

V4.2 是 V4.1 的增量版本。多页 `pages[]`、DocumentBlock、逐行编辑、背景检测、导出和字符级随机均保持原路径；本轮没有引入 OCR、透视或 AI。

## 纸张槽位排版

`lib/layout/block-layout-engine.ts` 继续以检测到的物理横线作为唯一纵向槽位。普通段落、列表、诊断、表格和处方边界不产生空槽；标题和签名前最多保留一个结构槽。可拆分长段落会消费当前页剩余槽位，标题、签名、表格行和处方行保持原子性。

处方 `auto` 在 A4 可写宽度下固定为四列。Canvas 渲染器按每个逻辑列宽独立计算收缩比例，长药名不会改变后续列锚点。签名每项一行、右对齐，并作为不可拆分 Block 参与正常分页。

## 页码决策

`footerMode` 支持 `auto | native | generated | hidden`。`auto` 读取页面保存的 `backgroundHasNativePageFooter` 或背景资源的 `hasNativePageFooter` 元数据，不执行 OCR。程序页码只在需要时绘制于页面底部中央；预览与 PNG/PDF 导出共用同一渲染函数。

## InkStyle

`lib/handwriting/ink-style.ts` 由文档 ID、Block/字段 ID、字体、参数和 Seed 产生低频相关的亮度、饱和度、透明度、洇墨与稀疏墨迹状态。稳定 key 不包含 pageIndex、坐标或背景，因此分页、拖动和切换背景不会改变墨迹。

## CorrectionStyle

手动涂改保存 `blockId + sourceStart/sourceEnd`，相对于原文字符而不是画布绝对坐标。渲染顺序为原文字符、墨迹效果、涂改覆盖和补写。涂改标记不进入 coverage 文本，因此不会改变原文完整性统计。

自动涂改默认关闭。启用后也只处理不含标识、时间、数字等敏感模式的叙述段落；诊断、处方、剂量、签名等结构直接排除。不确定时不生成。

## 兼容与性能

SchemaVersion 保持 3。V4.1 及更早的 V3 项目在反序列化时获得默认 `InkStyle`、`CorrectionStyle` 和 `footerMode`，原页面、手动偏移、字体和 Seed 原样保留。字符和墨迹状态均按完整字段缓存；页面仍按 Canvas 批量绘制，没有为每个字符创建 React/Konva 节点。
