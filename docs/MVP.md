# MVP 范围与开发任务

## MVP 范围

当前版本以提供的“格式.docx”为首个中医住院病历模板，形成完整路径：上传 DOCX、提取段落/表格、确认字段、按真实字宽排版、多页编辑、逐行拖动、统一撤销/重做、保存 V2 项目并导出 PNG/JPG/多页 PDF。

当前增量版本已提供 30 个字体资源位、30 个不同程序化背景、自定义字体和背景上传、字符级确定性扰动与项目 JSON。字体资源位不等于捆绑字体文件：只引用本机系统字体，并为用户持有合法授权的 TTF/OTF 保留位置。

## 目录结构

```text
handwrite-studio/
  app/                    页面与本地 API 入口
  components/editor/      上传、字段映射、画布、参数面板
  lib/handwriting/        字体/背景库、Seed、字符状态、Canvas 渲染与序列化
  lib/layout/             测宽、换行、分页、版面引擎与覆盖率校验
  lib/history/            通用历史记录
  lib/schema/             模板与项目 JSON Schema
  server/modules/         解析、映射、模板、布局、手写与导出
  templates/              模板 JSON 和受许可背景
  data/                   本机字体、背景、项目和验收导出（不提交）
  docs/                   架构、MVP 和格式说明
  tests/                  固定样本与回归测试
```

## V2 已完成任务

1. 文档契约：定义 Document、Template、LayoutLine 和 ExportPreset，并提供 JSON Schema。
2. DOCX 解析：提取段落、表格、标题和页面信息；不对 DOCX 使用 OCR。
3. 首个模板：把“格式.docx”中的基本信息、主诉、现病史、既往史、个人史、体格检查和诊断等栏目建模。
4. 字段映射：以标题、冒号标签和别名规则产生候选映射，所有结果先让用户确认。
5. 自动排版：按实际 Canvas 字宽分行，处理标点禁则、字段溢出和续页。
6. 编辑器：每行独立选中和拖动，支持字号、字距、行距、旋转、撤销与重做。
7. 导出：浏览器预览与高分辨率重绘同源，按 150、300、600 DPI 生成 PNG/JPG，并由本地后端合成多页 PDF。
8. 验收：使用无真实个人信息的样本测试 Windows 与 macOS 本地启动、分页和导出结果。

## 迭代路线

- 当前阶段：字符级自然化、稳定 Seed、字体/背景管理、真实多页、V2 Schema、统一历史与标准 A4 导出。
- 下一阶段：保存多个项目的管理页、页级增删/排序、更多模板区域规则和打印色彩校准。
- 后续阶段：在明确授权后再加入 OCR、横线检测、透视校正、笔画路径和涂改效果。
